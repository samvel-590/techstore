# TechStore

Витрина интернет-магазина электроники на React. Каталог с поиском, фильтрами и сортировкой, корзина, избранное, тёмная/светлая тема и детальные страницы товаров. Каталог поставляется вместе с приложением, а изображения товаров загружаются с [Fake Store API](https://fakestoreapi.com/).

## Стек

- **React 19 + Vite** — сборка и dev-сервер
- **React Router v6** — маршрутизация, анимированные переходы между страницами
- **Framer Motion** — анимации (переходы страниц, hover-эффекты, тосты, модалки)
- **Context API** — корзина, избранное, тема, уведомления
- **localStorage** — персистентность корзины/избранного/темы между сессиями
- **react-icons** — иконки

## Возможности

- 🔎 Поиск по названию, описанию и категории (с debounce)
- 🏷️ Фильтры по категории и диапазону цен
- 💰 Сортировка (цена, рейтинг, название)
- 🛒 Корзина: изменение количества, удаление, расчёт доставки, модалка оформления заказа
- ❤️ Избранное с сохранением между визитами
- 🌙 Переключение светлой/тёмной темы
- 📱 Полностью адаптивная вёрстка (мобильное меню, drawer с фильтрами)
- ✨ Skeleton-загрузка, анимации карточек, toast-уведомления, страница 404

## Запуск проекта

```bash
npm install
npm run dev       # dev-сервер, по умолчанию http://localhost:5173
npm run build     # продакшн-сборка в /dist
npm run preview   # локальный просмотр собранной версии
```

## Структура проекта

```
src/
  api/          # доступ к каталогу + поиск/фильтры/сортировка
  data/         # данные каталога
  components/   # переиспользуемые UI-компоненты
  context/      # Cart, Favorites, Theme, Toast
  hooks/        # useLocalStorage, useDebounce
  pages/        # Home, Catalog, ProductDetails, Cart, Favorites, NotFound
  styles/       # общие стили (кнопки, секции)
```

## Заметки

Это учебный/демонстрационный проект: оформление заказа в корзине не выполняет реальную оплату. Часть данных (скидки, метка "новинка") генерируется на клиенте поверх ответа API — сам Fake Store API их не отдаёт.
